# Cruce

Inglés cotidiano avanzado, entrenado en el punto exacto donde el español y el inglés se cruzan.

Advanced everyday English for a native Spanish speaker: production-first training — no recognition games, no points, no lives. Every lesson lives where the two languages diverge: phrasal verbs as a system, false friends that flip meaning (*molestar* is not *molest*), and the rest of the crossing points, with per-discrimination mastery, spaced review and timed production gates.

**Live:** https://oscarvelz.github.io/Cruce/

- Single self-contained `index.html` (plus the self-hosted Rajdhani fonts the Cyberpunk theme speaks in) — all progress lives in the browser (localStorage).
- Four themes: Day, Night (AMOLED discipline, ported from Brizna), Tron (ported from Weekly) and Cyberpunk (merged from Cadence + Faro). The Day/Night toggle remembers your last theme on each side.
- Version 2.15.0.
